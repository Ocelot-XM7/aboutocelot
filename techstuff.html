AI HOMELAB:

Designed and deployed a self-hosted AI homelab environment centered around LM Studio for local large language model inference. The platform hosts Meta's Llama 3.1 8B model for natural language processing tasks and Llama 3.2 multimodal models for image and vision-based workflows. To extend model capabilities beyond local knowledge, I integrated a self-hosted SearXNG search service, enabling internet-based information retrieval while maintaining control over privacy and infrastructure. The system provides a cloud-independent AI environment capable of conversational assistance, information retrieval, and multimodal analysis.

OS SIMULATION USING HTML+CSS+JS:

OcelotOS Simulation is a browser-based operating system that recreates the functionality and user experience of a modern desktop environment. It includes a complete window manager, virtual file system, application framework, process management, networking simulation, security controls, system services, persistence, customization options, and a suite of built-in applications. The platform supports multi-user workflows, desktop customization, package management, terminal operations, notifications, widgets, cloud features, and simulated hardware monitoring, all running entirely within the browser. Designed with modular architecture and persistent storage, it demonstrates how core operating system concepts can be implemented using modern web technologies.
